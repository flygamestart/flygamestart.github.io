사용 방법

FlyQRCode로 몇 초 만에 스캔 가능한 QR 코드를 만들 수 있습니다. 설치나 가입이 필요 없습니다.

빠른 시작

  1. 「QR 내용」에 URL, 텍스트, WiFi 문자열 붙여넣기;
  2. 프리셋 선택 또는 색상·모양·크기 조정;
  3. 필요 시 중앙 로고 추가;
  4. 「PNG 다운로드」 또는 「SVG 다운로드」 클릭.

활용 예

  • 마케팅 — 포스터·전단지 링크;
  • 이벤트 — 체크인, 경품, 자료 링크;
  • 매장 WiFi — 비밀번호 없이 연결;
  • 디지털 명함 — 연락처·SNS.

디자인 팁

인쇄용은 「미니멀 흑백」 프리셋과 충분한 여백을 권장합니다. 실제 기기로 테스트하세요.
