使用指南

FlyQRCode 讓您在幾秒內製作可掃描的 QR Code，無需安裝或註冊。

快速上手

  1. 在「QR Code 內容」貼上網址、純文字或 WiFi 字串；
  2. 選擇風格預設，或自訂顏色、碼點形狀與尺寸；
  3. 可選上傳中央 Logo；
  4. 點擊「下載 PNG」或「下載 SVG」。

常見用途

  • 網站推廣 — 海報與傳單連結；
  • 線下活動 — 簽到、抽獎；
  • 門市 WiFi — 顧客掃碼連線；
  • 電子名片 — 聯絡方式或社群。

設計建議

印刷建議使用「極簡黑白」並保留足夠靜區。正式使用前請用手機實測。
